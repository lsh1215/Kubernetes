Each concept should include root-cause context directly in the document instead of sending normal concept research to a separate folder.

Recommended shape:

```markdown

## 해결하려던 문제

## 기존 방식의 한계

## 핵심 아이디어

## 동작 방식

## 실습으로 확인하기

## 자주 헷갈리는 점

## References
```
