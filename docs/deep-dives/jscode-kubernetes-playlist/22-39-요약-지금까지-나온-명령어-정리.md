# 22. 3.9. [요약] 지금까지 나온 명령어 정리

- 영상: [쿠버네티스 입문·실전 - 3.9. [요약] 지금까지 나온 명령어 정리](https://www.youtube.com/watch?v=3spPR3gAiAo)
- 길이: 0분 48초
- 정리 기준: 한국어 자막/스크립트 기반 요약. 원문 스크립트는 저장하지 않음.

## 이 챕터의 핵심

- Deployment와 Service 실습에서 나온 명령어를 빠르게 정리한다.
- 리소스 조회, 적용, 삭제, 스케일, 롤아웃 확인이 핵심이다.

## 근원탐색 관점

Deployment와 Service는 Pod보다 추상화가 높기 때문에 리소스 간 관계를 조회하는 명령어 습관이 중요하다.

## 보기 전에 잡을 질문

- Deployment, ReplicaSet, Pod, Service를 각각 조회해 관계를 확인한다.

## 자막에서 확인한 키워드

- 파드
- 디플로이먼트
- 서비스

## 실습/명령어 포인트

- 영상 시청 중 나오는 명령어는 직접 실행하며 별도 lab 문서로 옮긴다.
