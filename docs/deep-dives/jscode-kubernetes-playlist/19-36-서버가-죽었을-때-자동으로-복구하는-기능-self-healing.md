# 19. 3.6. 서버가 죽었을 때 자동으로 복구하는 기능 (Self-Healing)

- 영상: [쿠버네티스 입문·실전 - 3.6. 서버가 죽었을 때 자동으로 복구하는 기능 (Self-Healing)](https://www.youtube.com/watch?v=gu9nSKpd4mA)
- 길이: 2분 14초
- 정리 기준: 한국어 자막/스크립트 기반 요약. 원문 스크립트는 저장하지 않음.

## 이 챕터의 핵심

- Deployment가 관리하는 Pod가 죽으면 쿠버네티스가 다시 생성해 원하는 상태를 복구한다.
- 이 동작은 장애를 완전히 없애는 것이 아니라, 선언된 상태와 실제 상태의 차이를 줄이는 컨트롤 루프다.
- Pod를 직접 삭제해도 Deployment가 새 Pod를 만드는 흐름을 확인한다.

## 근원탐색 관점

운영 환경에서는 프로세스와 서버가 언제든 죽을 수 있다. 사람이 매번 재시작하지 않도록 시스템이 원하는 상태를 지속적으로 맞춰야 한다.

## 보기 전에 잡을 질문

- Deployment가 만든 Pod 하나를 삭제하고 새 Pod가 생성되는지 본다.
- Self-Healing이 가능한 이유를 컨트롤러와 원하는 상태 관점으로 설명한다.
