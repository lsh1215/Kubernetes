# 03. 2.1. 파드(Pod)란?

- 영상: [쿠버네티스 입문·실전 - 2.1. 파드(Pod)란?](https://www.youtube.com/watch?v=UJssa3nc0FQ)
- 길이: 3분 3초
- 정리 기준: 한국어 자막/스크립트 기반 요약. 원문 스크립트는 저장하지 않음.

## 이 챕터의 핵심

- Pod는 쿠버네티스에서 컨테이너를 감싸는 가장 작은 배포 단위다.
- 보통 하나의 Pod 안에 하나의 애플리케이션 컨테이너를 두고, 필요할 때 밀접한 보조 컨테이너를 함께 둔다.
- Pod 단위로 IP, 네트워크, 실행 상태가 관리된다는 점이 핵심이다.

## 근원탐색 관점

컨테이너만 직접 관리하면 네트워크, 생명주기, 배치 단위가 흩어진다. 쿠버네티스는 컨테이너를 바로 스케줄링하지 않고 Pod라는 운영 단위로 묶었다.

## 보기 전에 잡을 질문

- Pod와 컨테이너의 차이를 한 문장으로 설명한다.
- Pod가 죽으면 내부 컨테이너도 함께 영향을 받는다는 생명주기 관점을 확인한다.
