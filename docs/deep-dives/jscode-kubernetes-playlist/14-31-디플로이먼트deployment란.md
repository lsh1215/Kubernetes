# 14. 3.1. 디플로이먼트(Deployment)란?

- 영상: [쿠버네티스 입문·실전 - 3.1. 디플로이먼트(Deployment)란?](https://www.youtube.com/watch?v=n0c-SUP-p5Q)
- 길이: 3분 16초
- 정리 기준: 한국어 자막/스크립트 기반 요약. 원문 스크립트는 저장하지 않음.

## 이 챕터의 핵심

- Deployment는 여러 Pod를 원하는 개수로 유지하고 업데이트하는 상위 리소스다.
- 직접 Pod를 여러 개 관리하는 대신 replicas와 template을 선언한다.
- Deployment는 ReplicaSet을 통해 Pod 개수를 맞추고 상태를 유지한다.

## 근원탐색 관점

Pod를 직접 여러 개 만들면 개수 유지, 장애 복구, 버전 업데이트가 모두 수동 작업이 된다. Deployment는 원하는 상태를 선언하면 컨트롤러가 실제 상태를 맞추게 만든다.

## 보기 전에 잡을 질문

- Pod와 Deployment의 차이를 원하는 상태 관리 관점에서 설명한다.
- replicas와 template의 의미를 확인한다.
