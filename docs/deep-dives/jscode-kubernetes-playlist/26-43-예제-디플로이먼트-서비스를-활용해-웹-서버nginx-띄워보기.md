# 26. 4.3. [예제] 디플로이먼트, 서비스를 활용해 웹 서버(Nginx) 띄워보기

- 영상: [쿠버네티스 입문·실전 - 4.3. [예제] 디플로이먼트, 서비스를 활용해 웹 서버(Nginx) 띄워보기](https://www.youtube.com/watch?v=me3Q6CsOjyQ)
- 길이: 4분 14초
- 정리 기준: 한국어 자막/스크립트 기반 요약. 원문 스크립트는 저장하지 않음.

## 이 챕터의 핵심

- k3s 환경에서 Deployment와 Service로 Nginx 웹 서버를 띄운다.
- 앞에서 배운 Deployment/Service 패턴이 실제 서버 환경에서도 동일하게 적용된다.
- 외부 접근 가능성을 확인하며 로컬 실습과 원격 실습의 차이를 체감한다.

## 근원탐색 관점

학습용 YAML이 실제 서버에서도 동작해야 운영 감각으로 이어진다. k3s는 같은 Kubernetes API를 사용하므로 앞선 리소스 모델을 그대로 적용할 수 있다.

## 보기 전에 잡을 질문

- k3s 클러스터에 Nginx Deployment와 Service를 적용한다.
- 브라우저 또는 curl로 외부 접근을 확인한다.

## 자막에서 확인한 키워드

- 파드
- 디플로이먼트
- 서비스
- k3s
