# 24. 4.1. What is k3s?

- 영상: [Kubernetes for Beginners and Practical Use - 4.1. What is k3s?](https://www.youtube.com/watch?v=1vbrnkaZlk4)
- 길이: 2분 48초
- 정리 기준: 한국어 자막/스크립트 기반 요약. 원문 스크립트는 저장하지 않음.

## 이 챕터의 핵심

- k3s는 가볍게 사용할 수 있는 Kubernetes 배포판이다.
- 학습이나 작은 서버 환경에서 쿠버네티스를 빠르게 설치하고 실습하기 위한 선택지로 소개된다.
- 표준 Kubernetes 개념을 더 작은 설치 부담으로 경험하는 데 초점이 있다.

## 근원탐색 관점

Kubernetes 전체 구성은 학습자나 작은 환경에는 무겁게 느껴질 수 있다. k3s는 더 가벼운 구성으로 Kubernetes 경험을 제공하려고 등장했다.

## 보기 전에 잡을 질문

- k3s가 Kubernetes 대체 개념이 아니라 가벼운 배포판이라는 점을 정리한다.
