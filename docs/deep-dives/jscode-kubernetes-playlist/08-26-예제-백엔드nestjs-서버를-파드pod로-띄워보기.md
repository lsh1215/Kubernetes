# 08. 2.6. [예제] 백엔드(Nest.js) 서버를 파드(Pod)로 띄워보기

- 정리 기준: 한국어 자막/스크립트 기반 요약. 원문 스크립트는 저장하지 않음.

## 이 챕터의 핵심

- Nest.js 백엔드도 Pod 매니페스트로 실행하며 Node 기반 서버 배포를 연습한다.
- Spring Boot 예제와 비교해도 Kubernetes 작성 패턴은 크게 달라지지 않는다.
- 반복 실습을 통해 Pod 생성, 확인, 접근, 삭제 흐름을 체화한다.

## 근원탐색 관점

프레임워크별 배포 방식을 따로 외우기보다, 컨테이너 이미지로 포장하면 쿠버네티스가 동일한 실행 모델로 다룰 수 있다.

## 보기 전에 잡을 질문

- Nest.js 서버 포트를 확인하고 Pod 매니페스트에 반영한다.
- 동일한 Pod 패턴으로 다른 백엔드도 실행할 수 있는지 확인한다.
