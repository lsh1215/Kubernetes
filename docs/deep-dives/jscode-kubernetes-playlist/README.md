## 사용 방법

1. 영상을 보기 전에 해당 챕터 파일의 `보기 전에 잡을 질문`을 먼저 읽는다.
2. 영상을 보며 명령어와 결과를 직접 실행한다.
3. 실습 결과는 `docs/labs/`에 기록한다.
4. 개념이 안정화되면 `docs/concepts/` 문서로 승격한다.
