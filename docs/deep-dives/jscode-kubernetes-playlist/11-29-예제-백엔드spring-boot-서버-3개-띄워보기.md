# 11. 2.9. [예제] 백엔드(Spring Boot) 서버 3개 띄워보기

- 영상: [쿠버네티스 입문·실전 - 2.9. [예제] 백엔드(Spring Boot) 서버 3개 띄워보기](https://www.youtube.com/watch?v=kzsEIZ3bIvc)
- 길이: 3분 6초
- 정리 기준: 한국어 자막/스크립트 기반 요약. 원문 스크립트는 저장하지 않음.

## 이 챕터의 핵심

- 동일한 백엔드 Pod를 여러 개 띄워 수평 확장의 감각을 잡는다.
- 직접 Pod를 여러 개 만들면 개수 관리와 장애 대응이 번거롭다는 한계가 드러난다.
- 이 한계가 다음 장의 Deployment 필요성으로 이어진다.

## 근원탐색 관점

서버를 여러 개 띄우는 것은 확장의 출발점이지만, 사람이 직접 개수를 맞추는 방식은 운영에서 쉽게 깨진다.

## 보기 전에 잡을 질문

- 동일한 Pod를 여러 개 만들 때 이름 충돌과 관리 부담이 생기는지 확인한다.
- 왜 Deployment가 필요한지 스스로 질문한다.

## 자막에서 확인한 키워드

- 파드
- 디플로이먼트
- 서비스

## 실습/명령어 포인트

- 영상 시청 중 나오는 명령어는 직접 실행하며 별도 lab 문서로 옮긴다.
