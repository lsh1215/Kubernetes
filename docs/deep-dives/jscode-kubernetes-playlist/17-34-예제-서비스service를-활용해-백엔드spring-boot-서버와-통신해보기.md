# 17. 3.4. [예제] 서비스(Service)를 활용해 백엔드(Spring Boot) 서버와 통신해보기

- 영상: [쿠버네티스 입문·실전 - 3.4. [예제] 서비스(Service)를 활용해 백엔드(Spring Boot) 서버와 통신해보기](https://www.youtube.com/watch?v=80TJCAO5U4c)
- 길이: 8분 47초
- 정리 기준: 한국어 자막/스크립트 기반 요약. 원문 스크립트는 저장하지 않음.

## 이 챕터의 핵심

- Service를 만들어 여러 백엔드 Pod에 접근하는 실습이다.
- 클라이언트는 개별 Pod가 아니라 Service 주소를 바라본다.
- Service가 Pod들을 묶어 트래픽 진입점을 제공하는 구조를 확인한다.

## 근원탐색 관점

백엔드 Pod가 여러 개이거나 재시작될 수 있어도 호출하는 쪽은 안정적인 주소 하나를 원한다. Service가 이 의존성을 끊어준다.

## 보기 전에 잡을 질문

- Deployment와 Service의 selector/label 연결을 확인한다.
- Service 경유 호출과 Pod 직접 호출의 차이를 비교한다.

## 자막에서 확인한 키워드

- 파드
- 디플로이먼트
- 서비스
