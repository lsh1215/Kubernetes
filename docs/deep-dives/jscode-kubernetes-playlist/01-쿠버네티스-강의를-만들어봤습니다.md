# 01. 쿠버네티스 강의를 만들어봤습니다!

- 영상: [비전공자도 이해할 수 있는 쿠버네티스 강의를 만들어봤습니다!](https://www.youtube.com/watch?v=3VT7Suh9HIw)
- 길이: 2분 16초
- 정리 기준: 한국어 자막/스크립트 기반 요약. 원문 스크립트는 저장하지 않음.

## 이 챕터의 핵심

- 비전공자도 따라올 수 있도록 쿠버네티스 입문과 실전 흐름을 짧은 챕터로 나눈 강의 소개다.
- 전체 학습은 Pod, Deployment, Service, k3s 실습으로 이어지며, 개념과 명령어를 반복적으로 연결하는 방식이다.

## 근원탐색 관점

컨테이너를 여러 개 운영하기 시작하면 배포, 확장, 장애 복구를 사람이 직접 처리하기 어렵다. 쿠버네티스는 이 반복 운영 문제를 표준화하려고 등장했다.

## 보기 전에 잡을 질문

- 전체 플레이리스트의 순서를 먼저 훑고 Pod -> Deployment -> Service -> k3s 순서로 큰 지도를 잡는다.
