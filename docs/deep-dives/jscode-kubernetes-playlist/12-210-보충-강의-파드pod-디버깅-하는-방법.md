# 12. 2.10. [보충 강의] 파드(Pod) 디버깅 하는 방법

- 영상: [쿠버네티스 입문·실전 - 2.10. [보충 강의] 파드(Pod) 디버깅 하는 방법](https://www.youtube.com/watch?v=btd7r1u1dsM)
- 길이: 5분 50초
- 정리 기준: 한국어 자막/스크립트 기반 요약. 원문 스크립트는 저장하지 않음.

## 이 챕터의 핵심

- Pod가 정상 실행되지 않을 때 상태, 이벤트, 로그를 확인하는 방법을 다룬다.
- describe는 이벤트와 스케줄링/이미지 오류를 보는 데 유용하고, logs는 컨테이너 프로세스 출력을 보는 데 유용하다.
- 문제가 생겼을 때 YAML, 이미지, 포트, 컨테이너 로그를 순서대로 좁혀간다.

## 근원탐색 관점

분산 환경에서는 실패 원인이 애플리케이션 코드, 이미지, 네트워크, 스케줄링 중 어디에 있는지 바로 보이지 않는다. 디버깅 명령은 이 원인을 계층별로 좁히기 위해 필요하다.

## 보기 전에 잡을 질문

- kubectl get pods, describe pod, logs를 구분해서 사용한다.
- Pod 상태가 Pending, Running, Error, CrashLoopBackOff 중 어디인지 먼저 본다.
