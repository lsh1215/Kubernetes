# 21. 3.8. [예제] 디플로이먼트, 서비스를 활용해 백엔드(Nest.js) 서버 띄워보기

- 길이: 13분 52초
- 정리 기준: 한국어 자막/스크립트 기반 요약. 원문 스크립트는 저장하지 않음.

## 이 챕터의 핵심

- Nest.js 백엔드를 Deployment와 Service 조합으로 배포한다.
- Pod 단독 실습에서 배운 내용을 운영에 가까운 구조로 확장한다.
- Deployment는 실행 개수와 업데이트를, Service는 접근 경로를 담당한다.

## 근원탐색 관점

실제 서비스는 단일 Pod 실행만으로 끝나지 않는다. 안정적인 운영에는 복제, 복구, 접근 추상화가 함께 필요하다.

## 보기 전에 잡을 질문

- Nest.js Deployment와 Service YAML을 함께 작성한다.
- Service를 통해 여러 Pod 중 하나로 트래픽이 전달되는지 확인한다.

## 자막에서 확인한 키워드

- 파드
- 디플로이먼트
- 서비스
