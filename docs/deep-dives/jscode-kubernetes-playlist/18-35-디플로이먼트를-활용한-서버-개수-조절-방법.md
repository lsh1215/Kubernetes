# 18. 3.5. 디플로이먼트를 활용한 서버 개수 조절 방법

- 영상: [쿠버네티스 입문·실전 - 3.5. 디플로이먼트를 활용한 서버 개수 조절 방법](https://www.youtube.com/watch?v=2WudZUNrY2w)
- 길이: 1분 54초
- 정리 기준: 한국어 자막/스크립트 기반 요약. 원문 스크립트는 저장하지 않음.

## 이 챕터의 핵심

- Deployment의 replicas 값을 바꿔 서버 개수를 조절한다.
- 수평 확장은 Pod 템플릿을 복제해 동일한 서버 인스턴스를 늘리는 방식이다.
- 선언한 원하는 개수와 실제 실행 개수를 컨트롤러가 맞춘다.

## 근원탐색 관점

트래픽 증가에 대응하려면 서버 수를 빠르게 늘리고 줄일 수 있어야 한다. Deployment는 수동 생성 대신 선언적 확장을 제공한다.

## 보기 전에 잡을 질문

- replicas 값을 변경한 뒤 Pod 개수가 따라오는지 확인한다.
- scale 명령과 YAML 수정 방식의 차이를 비교한다.

## 자막에서 확인한 키워드

- 파드
- 디플로이먼트
- 서비스
