# 02. 1.1. What is Kubernetes?

- 영상: [Kubernetes for Beginners and Practical Use - 1.1. What is Kubernetes?](https://www.youtube.com/watch?v=_M4oY7aK9ck)
- 길이: 2분 54초
- 정리 기준: 한국어 자막/스크립트 기반 요약. 원문 스크립트는 저장하지 않음.

## 이 챕터의 핵심

- 쿠버네티스는 다수의 컨테이너를 효율적으로 배포, 확장, 관리하기 위한 오픈소스 시스템이다.
- Docker가 컨테이너 실행 단위에 집중한다면, 쿠버네티스는 여러 컨테이너를 여러 서버에 걸쳐 운영하는 문제를 다룬다.
- 강의는 자동 배포, 확장, 복구 같은 운영 이점을 초반에 큰 그림으로 잡는다.

## 근원탐색 관점

컨테이너 하나를 띄우는 것은 쉽지만, 실제 서비스에서는 여러 서버와 여러 컨테이너를 안정적으로 유지해야 한다. 이 운영 복잡도를 줄이기 위해 오케스트레이션이 필요해졌다.

## 보기 전에 잡을 질문

- 쿠버네티스를 컨테이너 실행 도구가 아니라 컨테이너 운영 자동화 시스템으로 설명할 수 있는지 확인한다.
