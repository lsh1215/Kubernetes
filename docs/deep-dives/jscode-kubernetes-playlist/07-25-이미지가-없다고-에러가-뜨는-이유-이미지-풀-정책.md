# 07. 2.5. 이미지가 없다고 에러가 뜨는 이유 (이미지 풀 정책)

- 영상: [쿠버네티스 입문·실전 - 2.5. 이미지가 없다고 에러가 뜨는 이유 (이미지 풀 정책)](https://www.youtube.com/watch?v=tkdDEMGl0tQ)
- 길이: 8분 28초
- 정리 기준: 한국어 자막/스크립트 기반 요약. 원문 스크립트는 저장하지 않음.

## 이 챕터의 핵심

- Pod 생성 실패의 흔한 원인인 이미지 pull 오류를 다룬다.
- imagePullPolicy는 쿠버네티스가 이미지를 언제 다시 가져올지 결정한다.
- 로컬 이미지, 태그, 레지스트리 접근 가능 여부가 Pod 실행 성공에 직접 영향을 준다.

## 근원탐색 관점

컨테이너는 이미지가 있어야 실행된다. 클러스터 노드가 이미지를 찾거나 내려받지 못하면 애플리케이션 문제가 아니라 배포 준비 문제로 실패한다.

## 보기 전에 잡을 질문

- ImagePullBackOff 또는 ErrImagePull 상태를 보면 이미지 이름, 태그, 레지스트리를 먼저 확인한다.
- 로컬 실습과 원격 클러스터에서 이미지 접근 조건이 다르다는 점을 정리한다.
