# 09. 2.7. [예제] 프론트엔드(HTML, CSS, Nginx) 서버를 파드(Pod)로 띄워보기

- 길이: 5분 40초
- 정리 기준: 한국어 자막/스크립트 기반 요약. 원문 스크립트는 저장하지 않음.

## 이 챕터의 핵심

- HTML, CSS 정적 파일을 Nginx 컨테이너로 서빙하는 프론트엔드 Pod 실습이다.
- 프론트엔드도 결국 HTTP 서버 컨테이너로 실행되며, Kubernetes 입장에서는 일반 Pod와 같다.
- 정적 자산을 이미지에 포함하고 Nginx가 이를 제공하는 구조를 확인한다.

## 근원탐색 관점

브라우저가 접근하는 프론트엔드도 배포 관점에서는 컨테이너화된 웹 서버다. Kubernetes는 백엔드와 프론트엔드를 같은 운영 모델로 배치할 수 있게 한다.

## 보기 전에 잡을 질문

- 정적 파일이 포함된 Nginx 이미지를 Pod로 띄운다.
- port-forward로 프론트엔드 화면이 열리는지 확인한다.
